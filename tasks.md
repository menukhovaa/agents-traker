## 3. Предложенные приёмочные проверки

### Начальные данные

- [ ] Отображаются три задачи.
- [ ] Общие часы = 8.
- [ ] Выполненные часы = 2.
- [ ] Прогресс = 25%.

### Добавление и валидация

- [ ] Корректная задача добавляется с done=false.
- [ ] Название из пробелов отклоняется.
- [ ] Пустое название отклоняется.
- [ ] Пустые часы отклоняются.
- [ ] Отрицательные часы отклоняются.
- [ ] Часы менее 0,5 отклоняются.
- [ ] Часы более 24 отклоняются.
- [ ] Некратные 0,5 часы отклоняются.
- [ ] Нечисловые часы отклоняются.
- [ ] Ошибки отображаются рядом с полями.
- [ ] После ошибки значения формы сохраняются.

### Изменение задач

- [ ] Переключение done действительно меняет данные.
- [ ] Выполнение «Практики» даёт 6/8 ч и 75%.
- [ ] Удаление задачи исключает её из данных.
- [ ] После удаления всех задач показатели равны 0.
- [ ] При пустом списке отсутствуют NaN и Infinity.

### Фильтры

- [ ] «Все» показывает все задачи.
- [ ] «Активные» показывает только done=false.
- [ ] «Готовые» показывает только done=true.
- [ ] При фильтре «Активные» исходный прогресс остаётся 25%.
- [ ] Фильтры не изменяют исходные данные.
- [ ] Часы и прогресс не зависят от фильтра.

### Интерфейс

- [ ] На ширине 390 px текст читается.
- [ ] Горизонтального скролла нет.
- [ ] Поля имеют подписи.
- [ ] Кнопки имеют понятные подписи.
- [ ] Изменения отображаются после действий.

### Автономность

- [ ] A работает без дополнительных файлов.

- [ ] Нет CDN, внешних библиотек и API-ключей.
