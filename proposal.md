# Proposal: Мини-трекер учебных задач

## Цель

Создать автономный мини-трекер учебных задач на неделю, позволяющий добавлять и удалять задачи, отмечать их выполнение, фильтровать список и отслеживать затраченное по плану время и прогресс.

## Границы проекта

### Входит в объём

- Отображение списка задач.
- Добавление задачи с названием и оценкой времени в часах.
- Удаление задачи.
- Переключение статуса выполнения.
- Фильтрация: все / активные / готовые.
- Расчёт общих часов, выполненных часов и процента выполнения.
- Валидация полей с отображением ошибок.
- Адаптивный интерфейс для экранов шириной от 390 px.
- Работа без CDN, внешних библиотек и API-ключей.

### Не входит в объём

- Серверная часть и авторизация.
- Синхронизация между устройствами.
- Редактирование существующих задач, кроме статуса done.
- Даты, дедлайны и календарное планирование.
- Внешние API и сторонние зависимости.

## Варианты реализации

### A — единый HTML-файл

Результат: `tracker-v2.html`.

Внутри находятся HTML, CSS и JavaScript. Файл должен работать автономно в обычном браузере.

### B — модульная структура

Результат:

- `index.html` — разметка.
- `styles.css` — оформление.
- `app.mjs` — интерфейс и обработка действий.
- `domain.mjs` — операции с данными, валидация и расчёты.
- `tests/acceptance.test.mjs` — приёмочные тесты.

Вариант B также не использует внешние зависимости.

## Необязательное улучшение

Хранение задач в localStorage. Если хранилище недоступно, приложение продолжает работать в памяти и показывает понятное сообщение.

## Критерий готовности

Обе реализации соответствуют одной спецификации и проходят одинаковые приёмочные сценарии.
